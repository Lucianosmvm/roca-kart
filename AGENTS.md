# Preferências do usuário

- Não executar testes neste PC: inclui testes automatizados, verificações de sintaxe, benchmarks e scripts de validação. Não abrir o jogo ou o navegador para testar. Só mudar essa regra se o usuário autorizar explicitamente.
- Ler e editar os arquivos do projeto está autorizado. O Blender pode ser usado em segundo plano para gerar e salvar os modelos solicitados, sem abrir janelas ou rodar o jogo.
- Sempre salvar os modelos e peças 3D novos ou alterados para reutilização: fontes editáveis em `blender/models/*.blend` e exportações do jogo em `assets/*.glb`. Manter o script de geração correspondente no projeto.
- Informar na entrega quando as alterações não foram testadas. Não confundir a geração de arquivos 3D com testes do jogo.
